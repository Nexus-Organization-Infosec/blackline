# Security Policy

## Supported versions

Security fixes are provided for the latest development branch and the latest
released version of Blackline.

## Reporting a vulnerability

Do not report security vulnerabilities through public issues.

Use the repository's private security-advisory reporting feature instead:

<https://github.com/Nexus-Organization-Infosec/blackline/security/advisories/new>

Include a clear description, reproduction steps, affected versions, and any
relevant proof of concept. Please avoid accessing data or systems that you do
not own or have permission to test.

We will acknowledge reports as soon as practical, investigate the issue, and
coordinate disclosure with the reporter when a fix is ready.
